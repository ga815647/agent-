# Chat Dev W — Stable Interface Shadow

Status: SHADOW / NON-AUTHORITATIVE

`W` is Chat Dev's bounded execution capability. Use only when BRAIN/O actually selects bounded Worker execution; do not preload during ordinary work.

## Interface

Use W when substantial bounded work can reach a useful checkpoint without continuous O judgment and delegation is worth its context/latency cost.

`O` supplies:
- objective;
- scope/out-of-scope;
- authority and read path;
- acceptance criteria;
- stop condition;
- required return evidence.

`W` may invoke BRAIN when it encounters a material control boundary.

`W` may not:
- invoke another W;
- expand its own scope or authority;
- treat BRAIN as authorization for a new side effect;
- make final acceptance or commitment decisions.

If wider scope, new authority, or more Worker execution is needed, return to O.

Worker output is evidence only. O accepts/rejects it and retains final commitment authority.

## Detailed semantics during shadow

Production Worker transport/routing remains governed by `../chat-dev-control-plane-v0/ARCHITECTURE.md` until an explicit future promotion changes authority.
